# 🚀 MaintApp (Laravel)

Application web développée avec le framework **Laravel (PHP)** permettant la gestion des interventions de maintenance et l'authentification des utilisateurs.

---

## 🌟 Fonctionnalités Principales

- **Système d'Authentification** : Inscription (`Register`), Connexion (`Login`) et déconnexion sécurisées.
- **Gestion des Interventions** : Consultation, ajout, modification et suppression des demandes d'intervention.
- **Gestion des Catégories** : Organisation des interventions par type ou domaine.
- **Espace Administrateur** : Interface dédiée au suivi et à l'administration des données.
- **Sécurité** : Protection des routes, gestion des sessions et hachage des mots de passe.

---

## 🛠️ Stack Technique

- **Backend** : Laravel (PHP)
- **Frontend** : Blade Templates, HTML5, CSS3, JavaScript
- **Base de Données** : MySQL (XAMPP / phpMyAdmin)
- **Gestion de Version** : Git / GitHub

---

## 📁 Structure du Projet

app/          Logique applicative (Contrôleurs, Modèles, Middleware)
database/     Migrations et configurations de la base de données
resources/    Vues Blade, templates et styles d'interface
routes/       Définition des routes web et API
